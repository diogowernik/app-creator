# Checklist de migração

- [ ] Seleção inicial de conteúdo e jornadas definida.
- [ ] Origem preservada e consultada somente para leitura.
- [ ] Conteúdo, relações, ordem e arquivos conferidos no destino.
- [ ] Repetição não duplica dados silenciosamente.
- [ ] Jornadas úteis validadas durante testes de usabilidade.
- [ ] Mudanças de UX avaliadas pelo resultado, sem fidelidade obrigatória à tela antiga.
- [ ] Limitações e dados não migrados registrados.
